# 雅趣麻将 · 全平台联机版

一个浏览器里即可游玩的精致真实风格麻将游戏，**电脑与手机可在同一房间联机对战**：

- 🀄 **精致牌桌**：木纹牌桌、绒布桌面、真实矢量牌面（CC0 公有领域高清素材，清晰可辨识），带高光、阴影、出牌动画与程序化音效。
- 🎮 **多玩法预设**：广东麻将（鸡胡）、国标麻将（8 番点起胡）、四川麻将（简版·缺一门）、香港麻将（3 番起胡）、癞子麻将（4 癞），以及完全自定义。
- ⚙️ **自由自定义**：万/筒/条、字牌（中·發·白）、风牌（東·南·西·北）开关，癞子 0~8 张，起胡番数，吃/碰/杠开关，底分，庄家翻倍，缺一门。
- 🧮 **计分翻倍**：广东/香港/四川/自定义按 `底分 × 2^番` 翻倍计分；国标按番点累加。支持自摸、点炮、抢杠、杠上开花、海底捞月、天胡、地胡、大/小三元、大/小四喜、清一色、七对、十三幺、九莲宝灯、绿一色等数十种番型。
- 🌐 **公网联机**：权威服务器裁决，房间码建房/加入（1~4 人，空位电脑补位），断线自动托管、`sessionId` 重连恢复，出牌 25 秒/响应 8 秒倒计时。
- 📱 **全平台**：一个 Web 客户端通吃电脑与手机；手机横屏布局、点选+确认出牌、PWA 可添加到主屏幕。

## 运行方法

```bash
cd mahjong
npm install          # 首次运行（安装 ws 依赖）
npm start            # 同时启动网页与 WebSocket 服务器（默认 8000 端口）
```

浏览器打开 http://localhost:8000 ：

- **单机对战**：选玩法 → 自定义牌张/癞子 → 与 3 个电脑对战。
- **联机对战**：创建房间 → 把 6 位房间码发给朋友 → 朋友加入 → 房主开始。电脑和手机浏览器都可加入同一房间。

> 公网部署（让外网朋友能连）见 [`docs/DEPLOY.md`](docs/DEPLOY.md)。

## 操作

| 操作 | 说明 |
| --- | --- |
| 点击手牌 | 电脑端轮到你时直接出牌 |
| 点选手牌 → 出牌 | 手机端先点选，再点「出牌」确认（防误触） |
| 胡 / 碰 / 杠 / 吃 / 过 | 出现按钮时点击响应 |
| 规则设置 | 单机模式顶部按钮换玩法；联机模式查看房间信息 |
| 🔊 | 音效开关（WebAudio 程序合成，无外部资源） |

## 规则要点

- 发牌 13 张，庄家先摸 14 张；胡牌需 4 组面子 + 1 对将（或七对、十三幺等特殊胡型）。
- **癞子**：开局翻一张指示牌，其后连续 N 张（N=癞子数）为万能牌，可代替任意牌参与顺子/刻子/将/七对/十三幺。
- **计分**：番倍玩法总分 = `底分 × 2^总番`；自摸三家各付一份，点炮放炮者单付；抢杠胡由杠家支付。国标玩法按番点累加（≥8 点起胡）。
- 番型互斥按“计大不计小”处理（例如大三元不计箭刻），避免重复计番。

## 联机架构（已实现）

- **权威服务器**：`server/server.js` 持有 `MahjongEngine`，所有动作先经 `take()` 全量规则校验，再按座位视角过滤后广播 `sync`（别人手牌只含张数）与 `event`。
- **房间**：6 位房间码建房/加入；1~4 人，空位 `BotPlayer` 补位；房主开局；空房自动回收。
- **断线保护**：掉线立即由机器人托管；客户端自动重连并凭 `sessionId` 恢复座位与快照；大厅座位保留 60 秒。
- **防挂机**：出牌 25 秒、碰杠吃胡响应 8 秒，超时自动出牌/过。
- **全平台**：同一套网页在电脑与手机运行；手机横屏 + 点选出牌，PWA 可安装。
- 协议细节见 [`docs/NETWORK_PROTOCOL.md`](docs/NETWORK_PROTOCOL.md)。
